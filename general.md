# General

- Always update the plan. When discussing design decisions (answering questions, giving recommendations), apply the outcome to the plan in the same turn.
- Never assume. Ask questions with the `AskUserQuestion` tool, not as a list at the end of a chat reply. Provide recomendations. Ask before writing something that hinges on an ambiguous decision
- Never commit or push without asking. When work is ready, ask via AskUserQuestion and proceed only on a yes. Leave changes in the working tree and offer to commit/push at natural checkpoints. Approval for one commit doesn't cover the next.
